Page Pet for Chrome, Edge and Brave

Page Pet is a free virtual pet extension. One version works in every Chromium-based browser: Google Chrome, Microsoft Edge, Brave, Opera, Vivaldi and Arc.

Add to Chrome free Add to Edge

Install it

  1. Chrome, Brave, Vivaldi or Arc: open Page Pet in the Chrome Web Store and click Add to Chrome, then Add extension.
  2. Microsoft Edge: use Add to Edge above for the Edge Add-ons store (see the Edge guide), or install from the Chrome Web Store after Edge asks to Allow extensions from other stores.
  3. Opera: install from the Opera add-ons site, or from the Chrome Web Store with Opera's "Install Chrome Extensions" helper.
  4. Reload tabs that were already open. The pet appears on pages you open or reload after installing.

Pin it to the toolbar

Click the puzzle-piece Extensions button next to the address bar, then the pin beside Page Pet. The cat-face button opens the popup where you feed your pet, throw it a ball, choose an animal and see its collection.

First things to try

  1. Click the pet to pat it, and drag it to pick it up.
  2. Rename it: click its name at the top of the popup.
  3. Pick a cat, dog, rabbit, fox, bear, panda, pig or frog.
  4. Read a long article to the end; your pet may dig you up a bookmark for its collection.

The pet isn't showing up

  • Reload the tab. Tabs opened before installing don't have the pet yet.
  • Some pages can't have it: browser settings pages, the new tab page, the extension stores and PDF viewers don't allow extensions to draw on them.
  • It might be hidden: open the popup and check Show on pages, whether it's snoozed, and whether this site is hidden.
  • Phones: Chrome on Android and iPhone doesn't support extensions, so Page Pet is desktop only.

Is it safe?

Page Pet never reads what you type or what pages say, ignores password and payment fields, and keeps everything in your browser. Chrome warns that it can "read and change data on all websites" because the pet is drawn on every page; it doesn't collect any of it. Read the privacy policy.
