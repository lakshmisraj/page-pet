Page Pet for Firefox

Page Pet is a free virtual pet add-on for Firefox on Windows, Mac and Linux. It needs Firefox 140 or newer.

Add to Firefox free

Install it

  1. Open Page Pet on addons.mozilla.org and click Add to Firefox.
  2. Firefox shows what the add-on can do. Click Add.
  3. Reload tabs that were already open; the pet appears on pages you open or reload.

Check your version under Firefox menu › Help › About Firefox. Older versions, including Firefox ESR 128, can't install it.

What Firefox's prompts mean

  • "Access your data for all websites": needed so the pet can walk on every page. Page Pet doesn't read page content, what you type, or where you browse.
  • Data collection: Page Pet declares that it collects nothing. Only if you choose to buy the optional Goodies pack does Firefox ask you to allow sharing payment status and an email address with the payment service, ExtensionPay.

Pin it to the toolbar

Click the Extensions (puzzle piece) button, then the gear beside Page Pet, and choose Pin to Toolbar. Its cat-face button opens the popup for feeding, playing, animals and the collection.

The pet isn't showing up

  • Reload the tab. Tabs opened before installing don't have it yet.
  • Some pages can't have it: about: pages, addons.mozilla.org, reader view and the PDF viewer don't allow add-ons to draw on them.
  • It might be hidden: open the popup and check Show on pages, snooze, and whether this site is hidden.
  • Firefox for Android: not supported yet; Page Pet is for desktop Firefox.
